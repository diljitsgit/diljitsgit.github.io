Every blog needs a first post, so here is mine: a short tour of how this site
is put together and why.

## The stack

- **[Astro](https://astro.build)** builds every page to plain HTML ahead of
  time. There is no framework running in your browser, only a few small
  scripts for the animated bits.
- **[Tailwind CSS](https://tailwindcss.com)** handles styling, with a handful
  of colour variables so the site follows your system's light or dark mode.
- **MDX** powers this blog. A post is a single file in `src/content/blog`, and
  its file name becomes the URL.
- **GitHub Pages** hosts it. Every push to `main` rebuilds and deploys the
  site through a GitHub Actions workflow.

## The hero

The background on the home page is a `<canvas>` filled with ASCII characters.
Two slow sine waves decide how "loud" each character is, the field brightens
around your pointer, and a click sends a ring rippling outwards.

The three keys are real, too. Hold <kbd>Ctrl</kbd> + <kbd>Alt</kbd> on the home
page and watch what happens.

```ts
// Two overlapping waves give a slow, uneven drift.
const wave =
  0.5 +
  0.25 * Math.sin(x * 0.012 + t * 0.5) +
  0.25 * Math.sin(y * 0.02 - t * 0.35);
```
